# ROLE

You are an expert computational medicinal chemist, cheminformatics scientist, structural biologist, and AI-for-drug-discovery researcher.

Your task is to develop and execute a scientifically rigorous **few-shot, explainable, stereochemistry-aware, transferable-feature drug-discovery workflow** for α9α10 nicotinic acetylcholine receptor (nAChR) positive allosteric modulators (PAMs).

The starting experimental dataset is extremely small:

* approximately 25 compounds
* approximately 5 active compounds
* approximately 20 inactive compounds
* CSV files contain at minimum:

  * SMILES
  * UM potency
  * % potentiation
* all compounds share a related/common chemical core
* activity is experimentally measured
* the ultimate objective is **not merely QSAR prediction**
* the objective is to discover **novel scaffolds/chemotypes that preserve potency-associated molecular features learned from this small series**

The final scientific question is:

> Can potency-associated, stereochemistry-dependent molecular features learned from a small congeneric α9α10 PAM series be transferred across structurally distinct scaffolds to identify novel experimentally active α9α10 PAM chemotypes?

Do NOT treat this as a conventional large-dataset QSAR problem.

The primary scientific concept should be:

**Transferable Activity Features (TAFs)**

rather than a black-box potency predictor.

# 6. FEW-SHOT LEARNING STRATEGY

Because n ≈ 25, do NOT train a large neural QSAR model from scratch.

Do not use:

* large GNN trained from scratch
* deep transformer trained from scratch
* large neural QSAR architecture
* complex ensemble whose apparent accuracy depends on overfitting

Instead use a combination of:

### A. Relative SAR learning

Learn relationships such as:

compound A > compound B

rather than relying only on absolute prediction.

### B. Similarity-based inference

Use molecular similarity to identify local SAR relationships.

### C. Descriptor/fingerprint evidence

Use simple interpretable models only as supporting evidence.

Potential models:

* ridge regression
* elastic net
* Gaussian process
* kernel methods
* random forest
* extremely randomized trees

Use these only as supporting models and compare their stability.

### D. Pretrained molecular representations

If a pretrained molecular encoder is available, use it as a fixed representation.

Do NOT fine-tune a large model on 25 molecules unless there is a compelling reason.

# 7. VALIDATION STRATEGY

Do not use ordinary random train/test splitting as the primary validation.

The dataset is too small and highly congeneric.

Use:

### Leave-one-compound-out

Evaluate whether conclusions remain stable when individual molecules are removed.

### Leave-one-active-out

Determine whether identified features depend disproportionately on one of the five active compounds.

### Feature stability analysis

Repeatedly perturb the dataset and measure whether the same molecular features remain important.

### Counterfactual validation

Modify important features and determine whether predicted activity changes consistently.

### Chemical-distance analysis

Measure whether feature/activity relationships survive increasing chemical distance.

Organize molecules into:

1. same scaffold
2. close analogue
3. bioisostere
4. moderate scaffold modification
5. distant scaffold
6. novel scaffold

The final goal is performance on categories 5–6.

Do NOT claim strong generalization from internal CV alone.

---

# 8. EXPLAINABLE SAR

Build an explainability layer using multiple independent methods.

Do not rely exclusively on SHAP.

Use:

### 1. Matched Molecular Pair analysis

Identify transformations associated with:

* increased potency
* decreased potency
* increased potentiation
* decreased potentiation

### 2. Feature attribution

Where a model permits:

* SHAP
* permutation importance
* integrated gradients
* atom attribution

Use these only as evidence, not proof.

### 3. Counterfactual analysis

For an active molecule:

remove/change one feature at a time.

Ask:

> What structural modification would most likely destroy the activity-associated signal?

For an inactive molecule:

ask:

> What minimal modification would introduce the predicted activity-associated feature?

### 4. Feature ablation

Remove candidate features from the representation and determine whether predictive/ranking performance decreases.

### 5. Stability analysis

A feature should only be considered important if its importance persists across:

* resampling
* models
* representations
* individual compounds

# 9. STEREOCHEMISTRY MUST BE FIRST-CLASS

Treat stereochemistry as a major scientific variable.

Do not collapse stereoisomers into the same molecule.

Explicitly analyze:

* R/S
* E/Z
* stereocenter count
* stereochemical descriptors
* 3D chirality
* orientation of functional groups

Where possible, calculate stereo-aware 3D descriptors.

For compounds with defined stereochemistry:

compare:

* stereoisomer A
* stereoisomer B

If stereoisomers are experimentally unavailable, mark conclusions as hypotheses.

Do not invent stereochemical activity differences.

For candidate generation:

* preserve known stereochemical preferences
* enumerate plausible stereoisomers when appropriate
* score stereoisomers separately
* prioritize experimentally testable stereochemical pairs

A candidate whose only difference is stereochemistry can be particularly valuable as a mechanistic experiment.

# 10. 3D TRANSFERABLE FEATURES

The key goal is to identify molecular features that can survive removal of the original scaffold.

Represent molecular features using:

* H-bond donor
* H-bond acceptor
* hydrophobic region
* aromatic region
* positive/negative electrostatic region
* steric volume
* halogen interaction where relevant
* spatial distances
* angles
* relative orientation
* 3D shape
* molecular field
* stereochemical orientation

For each active molecule generate a 3D feature representation.

Do not define the TAF as merely:

"contains functional group X."

Instead define it as:

> chemical feature + physicochemical identity + 3D location + spatial relationship + orientation + stereochemical context

For example:

"hydrophobic/aromatic feature positioned approximately X Å from an H-bond acceptor with a defined relative orientation"

rather than simply:

"aromatic ring."

The exact feature geometry must be learned from the molecules and not arbitrarily invented.

# 11. TRANSFERABLE ACTIVITY FEATURE (TAF) DISCOVERY

Construct a ranked set of candidate TAFs.

Each TAF should receive evidence from:

* MMP analysis
* activity ranking
* attribution
* counterfactual analysis
* ablation
* 3D field similarity
* stereochemical consistency
* receptor interaction evidence

For each TAF report:

| TAF | Evidence | Stability | Stereo dependence | 3D geometry | Confidence |
| --- | -------- | --------- | ----------------- | ----------- | ---------- |

Do not call a feature "transferable" merely because it is important in the original scaffold.

Define transferability explicitly.

Use:

$$
T(F)=
\frac{\text{number of diverse scaffolds retaining feature F and showing activity}}
{\text{number of diverse scaffolds containing feature F}}
$$

Initially this is a prospective hypothesis.

It becomes evidence for transferability only after testing on chemically distinct scaffolds.
